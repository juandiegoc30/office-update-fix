01 The story

It started with a message from my cousin.

He had Office Home & Business 2021 on his Apple Silicon Mac and asked me to help with a licensing error. He said Office had updated and was now asking for Microsoft 365. We checked his Microsoft account: the Office 2021 purchase was still there.

My first attempt was to remove the apps and download the installer again from the product page. That didn’t get us anywhere. The installer already included a recent version of Office.

While looking into it, I found a Reddit discussion describing a very similar problem. The suggestion was to return to an earlier release and remove Microsoft AutoUpdate so it wouldn’t replace it again. That’s why I made this project: to keep the background, links and steps in one place.

Did my license actually turn into a subscription?

The message or installer name alone doesn’t tell us that. What we know is that an activation error followed an update. The exact cause is still unconfirmed; this guide documents a possible recovery approach.

What we’re going to try

There are three parts. The assistant handles the changes; you handle the external backup and the checks afterward.

03 Step by step

Here’s how to use it.

You can double-click the assistant or use Terminal. Both do the same thing. Start with diagnostics: it won’t change Office.

1

Download and extract the tool

Download the project ZIP and extract it. Inside are Office-Update-Fix.command, the script and instructions. Office itself is not in the ZIP: the assistant downloads it directly from Microsoft.

Download the tool ↓
2

Open the assistant and choose Diagnose

Double-click Office-Update-Fix.command, choose English, then Diagnose. Look at the version shown for each app before continuing.

Assistant options
1Diagnose
2Recover Office
3Remove AutoUpdate

An overview of the options, not a Terminal screenshot.

macOS won’t open the file?

You don’t need to disable Gatekeeper. Inspect the code and use Terminal: type cd followed by a space, drag the extracted folder into the window and press Return. Then copy this command:

Terminal
bash scripts/office-update-fix.sh diagnose en
3

Run recovery once your backup is ready

Choose Recover Office from the menu. If you’re using Terminal, run the command below. You’ll be asked to confirm your license and external backup, then confirm again before any apps are replaced.

Terminal
bash scripts/office-update-fix.sh recover en

Here’s what the assistant does

  • Copies the usual Outlook data locations.
  • Downloads the official 16.113.4 installer without Teams and checks Microsoft’s signature.
  • Keeps the previous apps and installs Word, Excel, PowerPoint, Outlook and OneNote, even if you didn’t use them all before.
  • Removes AutoUpdate before and after installation, since the installer can add it back.

Run these commands as written, without adding sudo. The assistant asks for administrator access when needed. It never asks for your Microsoft account password.

4

Open Word and check that editing works

Sign in with the account that purchased Office 2021. Try creating and editing a document, then check Excel and PowerPoint. If the error remains, note the message; don’t start deleting licenses or profiles just to see what happens.

The key point is the account: use the one associated with your Office 2021 purchase.

If you only want to remove AutoUpdate

You can do that separately, without reinstalling Office. Choose Remove AutoUpdate in the assistant or run this command. It also asks for confirmation and keeps a copy of the components.

Terminal
bash scripts/office-update-fix.sh remove-autoupdate en

04 Outlook

Take your time with Outlook.

After checking Word, look at your accounts, “On My Computer” mail, folders, contacts and calendars. If anything is missing or Outlook requests an unexpected migration, stop. Don’t keep making changes to that same profile.

The script doesn’t delete profiles, licenses or Keychain. Even so, an earlier Outlook might not understand a profile that has already been updated. Keeping the files helps, but it can’t guarantee that everything will open as before.

Where the copies are kept

The assistant shows the exact paths when it runs. Keep both folders until you’ve checked all your data. You still need the external backup.

~/Library/Application Support/Office Update Fix/run.*/Library/OfficeUpdateFix.*

Custom profile locations and other users’ data need their own backup.

How to recover apps and data →

What stops it updating again?

Removing AutoUpdate stops updates handled by that program. Keep in mind that it affects every app using it, not just Office. It does not block the App Store, other updaters or manual installations.

Another Microsoft installer can also bring it back. If you install a Microsoft product later, run diagnostics again. The recovery guide explains how to re-enable updates when you want to.

Office 2021 support ended October 13, 2026. Staying on an older version means missing future security fixes. Keep that in mind when deciding how long to use this workaround.
